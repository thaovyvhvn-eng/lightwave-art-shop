# Lightwave Art Shop

Website bán họa cụ: pocket màu chiết, bộ màu Holbein, Sakura, HIMI và combo giấy, cọ.

- `index.html`: Trang chủ
- `danh-muc.html`: Danh mục (theo loại và theo hãng màu Holbein, Sakura, Phoenix)
- `cua-hang.html`: Cửa hàng (lọc, tìm kiếm, giỏ hàng)
- `danh-gia.html`: Đánh giá và feedback
- `style.css`, `script.js`: giao diện và chức năng dùng chung
- `images/`: ảnh sản phẩm

Sửa tên, giá, mô tả sản phẩm và thêm đánh giá của khách trong `script.js` (mảng `PRODUCTS` và `REVIEWS`).
Mỗi lần đưa code mới lên nhánh `main`, Vercel tự cập nhật trang web.
